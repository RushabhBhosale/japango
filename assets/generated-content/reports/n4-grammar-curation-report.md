# JapanGo N4 grammar curation report

This is **JapanGo's manually curated JLPT N4-aligned grammar curriculum**. It is an editorial curriculum, not an official or fixed JLPT grammar list. The source contains original classification metadata and concise formation summaries; it copies no textbook explanations, examples, exercises, or answer material.

## Rejected or N5-place rows

- Row 3, `あまり～ない`: Basic negative-polarity construction with no distinct N4 objective; add to the N5 editorial backlog.
- Row 48, `な`: Exact pattern and prohibitive meaning already exist as N5 grammar-na.
- Row 59, `にする`: Exact N5 grammar-nisuru point with no new formation or learning objective.
- Row 61, `の中で`: The supplied gloss is already covered compositionally and within N5 grammar-nonakade-gaichiban.
- Row 94, `ていた`: Past-continuous ～ていた is a direct tense expansion of the existing N5 ～ている lesson, not a separate N4 point.
- Row 117, `って`: Exact N5 grammar-tte casual quotation point with no extension.
- Row 122, `より`: N5 grammar-yori-nohouga already teaches the supplied comparison objective.

## Merged variants

- Row 25, `じゃないか` → `grammar-n4-dewa-nai-ka`: Colloquial variant of rhetorical or confirmation ～ではないか; the unsupported invitation sense was discarded.
- Row 45, `みたいな` → `grammar-n4-mitai-da`: Adnominal variant of ～みたいだ.
- Row 46, `みたいに` → `grammar-n4-mitai-da`: Adverbial variant of ～みたいだ.
- Row 52, `なければいけない` → `grammar-n4-nakereba-naranai`: ～なければいけない is the same obligation lesson as ～なければならない; retained as an alternate pattern.
- Row 82, `そうに・そうな` → `grammar-n4-souda-appearance`: Attributive and adverbial variants of appearance ～そうだ, never hearsay.
- Row 125, `ように / ような` → `grammar-n4-youda-similarity`: Similarity and manner variants of ～ようだ; purpose ～ように remains a separate record.

## Moved to vocabulary

- Row 13, `が必要`: 必要 plus ordinary subject marking is a vocabulary collocation, not a productive grammar identity.
- Row 32, `きっと`: Pure adverb.
- Row 40, `急に`: Pure adverb.
- Row 43, `または`: Lexical conjunction; the supplied gloss also incorrectly includes 'both'.
- Row 57, `に気がつく`: Lexical verb expression 気がつく, not a productive attachable grammar form.
- Row 72, `さっき`: Temporal adverb or noun.
- Row 76, `さすが`: Lexical evaluative adverb or expression.
- Row 78, `そんなに`: Demonstrative degree adverb.
- Row 121, `やっと`: Pure adverb.
- Row 129, `ぜひ`: Pure adverb.
- Row 130, `全然～ない`: Teach 全然 as vocabulary with negative-polarity usage; the candidate has no distinct N4 syntax objective.

## Unresolved

- Row 67, `おきに` → `grammar-n4-oki-ni-unresolved`: The gloss 'every' is unsafe: forms such as 一日おき can be interpreted as every other day and must be distinguished from ～ごとに.
- Row 119, `は〜が… は` → `grammar-n4-wa-ga-wa-unresolved`: Malformed and underspecified surface conflating contrast and comparison; no safe formation or meaning identity can be recovered.

Unresolved rows remain explicit non-release records in `grammar/n4.json` and the development bundle. They are excluded from the production bundle and curriculum units. OCR-only candidates remain a separate review report and cannot override the manual source.
